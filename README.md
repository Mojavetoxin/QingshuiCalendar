# 清水日历

一个**本地优先、完全离线**的 Android 日历 App：不申请 INTERNET 权限，所有数据只保存在你的手机上。

## 功能

- **月视图**：翻页浏览、今天按钮、周起始日可设（周一/周日）、农历 / 节气 / 法定节假日与调休标注（可分别开关）、有日程的日期显示圆点
- **年视图**：12 个迷你月，点击任意日期直接跳到月视图对应日
- **日程管理**：新建 / 编辑 / 删除 / 完成，支持时间、全天、地点、标签、8 种颜色、7 种重复规则（每天 / 每周 / 每月 / 每年 / 工作日 / 自定义周几）、提醒预设（到点及提前 5 分钟～1 天）
- **一句话导入**：输入「明天下午3点 在教室 开班会」自动解析出日期、时间、重复、提醒，预览确认后保存；解析不了会说明原因，可手动补全
- **文档每日导入**：选一个 txt / md 文档（每行一条日程），每天在设定时刻自动读取新增行并导入；同一行内容不会重复导入；解析失败的行进「待处理」列表，可重试 / 编辑 / 忽略
- **提醒通知**：日程到点前按设定提醒；Android 12+ 若未授予精确闹钟权限，自动降级为约 10 分钟窗口内的近似提醒
- **数据备份**：全部日程导出为 JSON，可随时恢复（换机 / 存档）
- **搜索与筛选**：按标题 / 备注 / 地点搜索，按完成状态筛选

## 在 GitHub 上云构建 APK（无需本地 Android 环境）

1. 解压 `QingshuiCalendar-web.zip`，得到 `QingshuiCalendar` 文件夹（或直接含工程文件的文件夹）
2. 在 GitHub 新建一个仓库，把文件夹里的**全部内容**上传（网页端拖拽上传即可，保留 `.github` 文件夹；若用 git，直接推整个文件夹也可以）
3. 仓库页 → **Actions** 标签 → 选中 **Build APK** → **Run workflow**（首次需要点按钮启用）；推送到 main / master 分支也会自动构建
4. 构建完成后（约 5～10 分钟），在该次运行页面底部 **Artifacts** 下载 `QingshuiCalendar-apk`
5. 下载得到 zip，解压出 `QingshuiCalendar-debug.apk`，传到手机安装（需允许安装未知来源应用）

> 私有仓库同样可用（免费账户每月 2000 分钟构建时长，够用）。
> 工程根自带 `gradle/wrapper/gradle-wrapper.jar`，CI 不需要额外下载 wrapper。

## 一句话解析语法速查

| 写法 | 结果 |
| --- | --- |
| 明天下午3点 开会 | 明天 15:00 |
| 周五晚上8点 健身 到9点半 | 最近周五 20:00–21:30 |
| 每周一 交周报 | 每周重复 |
| 下个月5号 交房租 | 下月 5 日 |
| 3天后 复习 | 3 天后 |
| 6月1日 全天 儿童节 | 当天全天 |
| #工作 明天9点到12点 复习 | 打标签「工作」 |
| 明天10点 提前半小时提醒 取快递 | 10:00，提前 30 分钟提醒 |

支持中文数字（如「下下周五」「十点半」「两小时后」）、 ISO 日期（2026-05-01）、「大前天 / 大后天 / 今晚 / 明晚」等。没有日期时间的行会进「待处理」，可手动补全。

## 节假日数据说明

法定节假日与调休数据覆盖 **2026—2030 年**；之后的年份按「周一至周五为工作日、周末为休息日」的规则推算，仅供参考，具体以国务院办公厅每年发布的安排为准。农历与节气按通用历法表推算。

## 隐私

- 不申请 `INTERNET` 权限，无任何网络请求、无统计 SDK
- 所有数据（日程、设置、导入记录）仅保存在本机数据库与设置存储中
- 备份文件只在你主动导出时写入你选择的位置

## 技术栈

Kotlin + Jetpack Compose (Material 3) + Room + DataStore + WorkManager + Navigation Compose；minSdk 26 / targetSdk 34；手写依赖容器，不使用 Hilt。
